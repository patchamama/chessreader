# book-comments-diagram-learning
Objective: bring the comments of the new English books into the commentary database, make the AI read diagrams without a FEN and learn from the user, and fix four notation problems of the reader. Branch: main (work-unit commits + tag). Delivery: ask-on-risk. Runners: Vitest (apps/web, packages/chess-shared, scripts), PHPUnit (apps/api); tsc + eslint last. Dev stack: app web :5180 / API :8090; the LLM console on :8777.
