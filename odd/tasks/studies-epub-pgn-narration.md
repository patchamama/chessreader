# studies-epub-pgn-narration
Objective: Lichess study -> library EPUB (with a conversion modal), the reverse (book -> PGNs reviewed in a generated-PGN area, downloadable, later uploadable to Lichess), notation/PGN bug fixes, AI "actions" to sync narration with the board, captured pieces on the analysis board, and a new analysis tab per opened game/study. Branch: main (work-unit commits + tag). Delivery: ask-on-risk. Runners: Vitest (apps/web, packages/chess-shared), PHPUnit (apps/api); tsc + eslint last.
