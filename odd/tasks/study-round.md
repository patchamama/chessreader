### Markup contract (S5, S9; producer: commentary/text writer; consumer: reader writer)
- A line of moves inside a comment, a variation or an engine evaluation: `<span class="chess-line" data-line-start="<FEN before the first move>" data-line-moves="<SAN SAN …>">` wrapping one `<span class="line-move" data-ply="<1-based index>">SAN</span>` per move (move numbers as plain text between them).
- A button that sends a line to a new analysis board: `<button type="button" class="line-to-board" data-line-start="…" data-line-moves="…">`.
- The source of a book comment: `<a class="comment-source" data-comment-game="<commentdb game id>" data-comment-ply="<ply>" href="#">`.
- These elements live inside `data-no-recognition` blocks (they are not the game's moves).
